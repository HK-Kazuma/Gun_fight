# BREACH & CLEAR — Tactical Response Unit

夜の市街地で武装グループの立てこもり事件に対応する、見下ろし型のタクティカル・アクションゲームです。
React と Canvas 2D で作っていて、PC ブラウザ（マウス＋キーボード）と、スマホの横画面（タッチ操作）の両方で遊べます。

> 撃つか、投降させるか。判断は、お前の一瞬に委ねられる。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。`npm run build` を実行すると `dist/` に静的ファイルが出力されます。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| W A S D | 移動 |
| SHIFT | ダッシュ（射撃精度が下がる） |
| マウス | 照準・フラッシュライトの向き |
| 左クリック | 射撃（長押しで連射） |
| R | リロード |
| F | 投降勧告（成功すると容疑者が手を上げる） |
| E | ドア突破／長押しで拘束・人質救出・爆弾解除 |
| Q / 右クリック | オペレーター固有のアビリティ |
| ESC | ポーズ |

### スマホ（横画面）の操作

タッチ端末では自動でタッチ操作に切り替わります（設定の「操作モード」で PC／スマホを固定することもできます）。

| ボタン | 内容 |
| --- | --- |
| 左スティック | 移動（画面左側のどこを触っても出せる） |
| DASH | ダッシュ（タップで切り替え） |
| 照準スティック | 照準。設定の「視点操作」で、固定（配置した場所に固定。画面右側のタップでも照準できる）か、移動（画面右側の触れた位置が中心になる）を選べる |
| 射撃ボタン | 射撃（押したままドラッグで照準も動かせる） |
| RELOAD / 投降勧告 / E / アビリティ | それぞれ R / F / E / Q と同じ |
| ⏸ | ポーズ |

### 設定とレイアウト編集
タイトル画面またはポーズメニューの **SETTINGS** から変更できます。
- ボタンと HUD の不透明度、カメラの距離、タッチ操作の細かい挙動
- **レイアウト編集**（PC 用とスマホ横画面用は別々に保存）：体力ゲージ、弾薬／リロードゲージ、オペレーション表示、ミニマップ、各ボタンなどをドラッグ＆ドロップで移動し、スライダーで大きさと不透明度を要素ごとに調整
- 設定は localStorage に保存されます

### 勝利条件
1. 人質を全員救出する
2. 容疑者を全員、逮捕または無力化する
3. （ZERO HOUR のみ）時限爆弾を解除する
4. 撤収ポイント（指揮車両の横の緑の枠）に戻る

### 交戦規定
- 容疑者を無力化すると +100、投降させて拘束すると +300。逮捕のほうが高得点です。
- 気付かれていない容疑者、体力が減った容疑者、スタン中の容疑者は投降しやすくなります。
- 投降した容疑者を撃つと規律違反で -500。人質を撃つと作戦失敗です。
- 赤いドラム缶は撃つと爆発します（人質を巻き込むと失敗）。

## オペレーター

| 名前 | 役割 | 武器 | アビリティ |
| --- | --- | --- | --- |
| HOLT | チームリーダー | M4 CARBINE | COMMAND：強力な投降勧告＋HP回復 |
| REYES | ブリーチャー | M870 SHOTGUN | FLASHBANG：範囲スタン（パッシブ：ドア突破時にスタン） |
| KANE | マークスマン | MK12 DMR | FOCUS：5秒間のスローモーション |
| PARK | テック／偵察 | MP5 SMG | RECON DRONE：壁越しに敵・人質・爆弾を表示 |

選ばなかった隊員のうち2名が分隊として自動で追従し、交戦中の敵だけを撃ちます。

## ミッション
0. **OPERATION BOOTCAMP**（チュートリアル）：訓練施設で、操作と隊員ごとの特徴を順番に学ぶ
   - 基本操作：移動・ダッシュ・射撃・リロード・ドア突破・投降と拘束・交戦・人質救出・撤収
   - HOLT：COMMAND で3人を一斉に投降させる
   - REYES：突入スタンで待ち伏せを崩し、閃光弾で固まった容疑者を無力化する
   - KANE：長いライトと DMR で遠距離戦、FOCUS で反撃をさばき、人質のそばの容疑者を精密射撃する
   - PARK：偵察ドローンで6部屋の配置を確かめ、75秒以内に爆弾を解除する
   - ブリーフィング画面で始める章を選べる。訓練中は倒れず、失敗するとその項目からやり直す
1. **OPERATION NIGHTFALL**：倉庫立てこもり事件（容疑者6・人質2）
2. **OPERATION HIGHRISE**：雑居ビル占拠事件（容疑者9・人質3・重武装1）
3. **OPERATION ZERO HOUR**：時限爆弾テロ（容疑者10・人質2・重武装2・制限時間3:30）

クリアするとスコアに応じて S / A / B / C のランクが付きます。実績は10種類あり、進行状況はブラウザの localStorage に保存されます。

## 演出と技術
- レイキャストで作った視界ポリゴンによるフラッシュライトと暗闇の表現
- 燃えるドラム缶と指揮車両の赤／青の回転灯による動的ライティング
- 火の粉、雨、硝煙、マズルフラッシュ、曳光弾、爆発、画面の揺れ
- BFS フローフィールドによる敵・分隊・人質の経路探索
- 効果音と環境音（雨・ドローン・遠くのサイレン）はすべて WebAudio でその場で合成しているため、音声ファイルは不要です
